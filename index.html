Methods being tested
  • fc-solve — Default: the baseline solver setup.
  • fc-solve — Optimize: asks fc-solve to shorten the solution path it finds.
  • fc-solve — Reparent: lets an already-seen state adopt a shorter route.
  • fc-solve — Optimize + reparent: combines both shortening features.
  • fc-solve — Best-First: uses fc-solve's Best-First search mode.
  • fc-solve — Soft-DFS: uses the stable Soft-DFS mode exposed by this WASM build.
  • Independent JS — Best-First: browser-native Best-First search.
  • Independent JS — A*: browser-native A* search.
  • Post-race optimizer: removes exact loops and one/two-move detours when the same future state can be reached more directly, then spends up to five seconds searching only for paths shorter than the current winner. Every final result is replay-validated.
